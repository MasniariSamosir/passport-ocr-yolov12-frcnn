# 🛂 PAS-OCR DL

## Passport OCR Based on Deep Learning

PAS-OCR DL is a web-based Optical Character Recognition (OCR) system developed for automatic passport information extraction using Deep Learning.

### Models Used

* YOLOv12
* Faster R-CNN
* EasyOCR
* Flask

---

## Research Publication

**Comparison of Faster R-CNN and YOLO v12 on Passport Text Extraction Based on Optical Character Recognition**

Published in SINTA 4 Journal.
