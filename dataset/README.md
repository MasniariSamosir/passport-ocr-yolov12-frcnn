# Dataset Information

This project utilizes a dataset consisting of 31 passport document images used for training, validation, and evaluation of the OCR system.

## Dataset Characteristics

* Total Images: 31 passport images
* Annotation Tool: Label Studio
* Annotation Format: YOLO and Faster R-CNN compatible formats
* Application Domain: Passport Information Extraction

## Extracted Fields

The dataset contains annotated passport information fields including:

* Passport Number
* Surname
* Given Names
* Nationality
* Place of Birth
* Date of Birth
* Sex
* Date of Issue
* Date of Expiry
* Machine Readable Zone (MRZ)

## Research Usage

The dataset was used to train and evaluate YOLOv12 and Faster R-CNN models for automatic passport information extraction based on Optical Character Recognition (OCR).

## Notes

Sample images are provided for demonstration purposes. The dataset is used exclusively for academic research and educational purposes.

For additional information regarding the dataset, please refer to the associated research publication available in the publication folder.
